# 混淆规则。只在 release 生效，见 build-profile.json5 的 buildOptionSet。
#
# 白名单的取舍标准只有一条：这个名字出了这个 HAP 之后，还有别人按字面量认它吗？
# ——落盘的 JSON、发给服务端的字段、卡片按 key 取的值、@Monitor 里的属性路径。
# 纯内部的类名、方法名、变量名一律不留。
#
# 混淆是全模块按名字统一改的，所以「同一次构建里写、同一次构建里读」本来不会出错。
# 下面留的这些，都是会被上一个版本写下的数据、或者被 App 之外的东西读到的。
