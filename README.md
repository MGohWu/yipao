## iOS 安装（自签）

未签名的 IPA 不能直接安装，需要用你自己的 Apple ID 重新签名。任选一种工具：

- **Sideloadly**（Windows / macOS）：
  1. 安装 Sideloadly，用数据线连接 iPhone，在电脑上信任该设备。
  2. 把 IPA 拖进 Sideloadly，填入你的 Apple ID，点 Start。
  3. 装好后到 iPhone「设置 → 通用 → VPN 与设备管理」，信任你的开发者证书。
  4. iOS 16 及以上还需要打开「设置 → 隐私与安全性 → 开发者模式」。
- **AltStore**：按 AltStore 官网说明装好 AltServer 和 AltStore，然后在 AltStore 里选择这个 IPA 安装。
- 其他支持「导入 IPA + Apple ID 签名」的工具同理。

### 限制与已知问题

- **免费 Apple ID 签的包 7 天后过期**，过期后需要重新签名安装（数据一般会保留）。付费开发者账号签的可用一年。
- 重签后 App Group 和钥匙串分组会被替换，**桌面小组件、锁屏控件和 App 之间的数据同步可能失效**。App 本身的控车功能不受影响。
- App 内置越狱与反调试检测，**越狱设备或 TrollStore 安装可能无法正常使用**。
- 需要登录零跑账号并使用你在官方 App 设置的 4 位控车密码。账号信息只保存在你的手机本地。
